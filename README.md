# Projector

## About
A game that lets users create a 2D platformer game using 3D objects.

On first load, users will go through a series of landing pages.

The game environment is a physical room. Users will select objects off a table, arranging them however they want before a white screen.

Then, when time is up, the casted shadows of these objects will become physical objects in the 2D platformer game.

Users will be loaded into this 2D environment to race, collecting points for various actions. At the end of the race, a winner will be selected and displayed. Then, they can return to the initial landing page(s).

## Technology
We are developing using XR Toolkit and ProBuilder, for Meta Oculus 3.

Multiplayer uses Netcode for GameObjects with Unity Multiplayer Services (Lobby + Relay). Players sign in anonymously; the host creates a private session of up to 4 players, and others join with its 6-character code. Lobby and Relay must be enabled for the project in the Unity Cloud dashboard.

## Scene flow

| Scene | What it is |
| --- | --- |
| `LandingMenu` | First load. **Host private game** (join by code), **host public game** (also findable by **join random game**), **join game with code** (keypad). Then the game-found screen: live code and players; only the host gets **START GAME**. |
| `ProjectorRoom` | 3D build phase: arrange objects from the table in front of the white wall. Hold an item still for 2 seconds to lock it in place; items cannot be locked while overlapping another item. |
| `Platformer2D` | 2D race graybox: flat wall, start/end platforms, avatar dummies, results scoreboard (mock data). |

The host's scene changes are synced to every player. Leaving, or the host closing the game, returns players to the landing menu.

Scenes are generated by editor scripts under the **Projector** menu. **Build Menu and 2D Scenes** rebuilds the landing menu objects and the 2D scene; the projector room is built by **Build Quest Room Scene** (needs the local Quaternius food pack).
