# Projector

## About
A game that lets users create a 2D platformer game using 3D objects.

On first load, users will go through a series of landing pages.

The game environment is a physical room. Users will select objects off a table, arranging them however they want before a white screen.

Then, when time is up, the casted shadows of these objects will become physical objects in the 2D platformer game.

Users will be loaded into this 2D environment to race, collecting points for various actions. At the end of the race, a winner will be selected and displayed. Then, they can return to the initial landing page(s).

## Technology
We are developing using XR Toolkit and ProBuilder, for Meta Oculus 3.

Multiplayer uses Netcode for GameObjects with Unity Multiplayer Services (Lobby + Relay). Players sign in anonymously; the host creates a private session of up to 4 players, and others join with its 6-character code. Lobby and Relay must be enabled for the project in the Unity Cloud dashboard.

## Scene flow

| Scene | What it is |
| --- | --- |
| `LandingMenu` | First load. **Host private game** (join by code), **host public game** (also findable by **join random game**), **join game with code** (keypad). Then the game-found screen: live code and players; only the host gets **START GAME**. |
| `ProjectorRoom` | The game itself, all in one room (below). |

In the projector room:

1. **Build.** Grab props off the table (grip) and let go to hang them in the projector's beam. The projector shows a live, stylized 2D drawing of each prop on the left wall, exactly where it sits in the beam. Hold a prop still for 2 seconds to lock it in place for everyone; a prop cannot be locked while it overlaps another one, and it turns red until you move it clear. You have 90 s, or press **PROJECT NOW** (or the projector's first button).
2. **Race.** The drawn shapes lock in as platforms with a coin over each, and everyone races on the wall: left thumbstick runs, A jumps. Points: 1000/750/500/250 by finish place, +100 per coin, -50 per fall. The host can **END RACE** early.
3. **Results** are projected on the wall. The host can **PLAY AGAIN** (back to building, props where they were and unlocked again) or anyone can **LEAVE**.

The projector films an off-screen 2D stage with an orthographic camera; the wall shows that image through `Projector/Projection Screen` (hotspot falloff, soft focus and glow, color fringing, scanlines, flicker, dust).

The host's scene changes are synced to every player. Leaving, or the host closing the game, returns players to the landing menu.

Scenes are generated by editor scripts under the **Projector** menu. **Build All Game Scenes** rebuilds the network prefabs and landing menu objects and re-adds the game to the projector room (the room itself is built by **Build Quest Room Scene**, which needs the local Quaternius food pack). **Build Quest APK** writes `Builds/Projector.apk`; install it on each headset with `adb install -r Builds/Projector.apk`.
