# Documentation

## Sprint 1 demo

[VR-SPRINT1.zip](VR-SPRINT1.zip) contains the original `VR-SPRINT1.mov` demo video.

The archive is stored with Git LFS. After cloning, install Git LFS and run
`git lfs pull` to download it, then extract it with:

```sh
unzip docs/VR-SPRINT1.zip -d docs
```

See the [project README](../README.md) for the game overview and setup details.
